From one skill to every agent

Write the skill, compile it, then install it where the agent reads.

  1. skill.yaml + SKILL.md

    Write

    Name and description in skill.yaml. Instructions in SKILL.md.

  2. skillprism build

    Compile

    Write one SKILL.md per agent under dist/. Nothing is installed yet.

  3. skillprism add

    Install

    Put the skill in the project or user directory that Claude, Codex, OpenCode, Factory, or Pi reads.

Install a skill from Git

Point add at a GitHub repository. List what is installed, update it when the repository changes, or remove it.

shell 
# install a skill from GitHub
$ skillprism add owner/repo

# list what is installed
$ skillprism list

# update when upstream moves
$ skillprism update

# remove a skill
$ skillprism remove my-skill

Compliant by construction

Each compiled skill includes the name and description the Agent Skills specification requires. skillprism validate checks that text before anything is written.

frontmatter
name · description
validate
format · length · empty
compile

Compile your first project

$ npm install -g skillprism
$ skillprism init project my-skills
$ cd my-skills && skillprism build
